# MyRec artwork

The icon is a left-facing hippopotamus that also reads as a vintage movie
camera. Its rounded body houses a large circular lens opening; its red eye
doubles as the recording light. A broad muzzle and small tooth identify the
hippo. The white silhouette sits on black.

Generated on 14 November 2026 with the built-in image generation tool.
The original YouRec elephant icon was used as a reference for the animal/camera
metaphor and minimal visual treatment. The hippo silhouette, left-facing
orientation and muzzle geometry were drawn anew.

`myrec-icon.png` is the full-size source. Android uses a 432 px adaptive layer
with the image inset to 328 px, plus 48/72/96/144/192 px legacy launchers derived
with ImageMagick. The adaptive inset keeps the wide muzzle inside launcher masks.

The MyRec name and icon are branding assets excluded from the source-code
license; see [LICENCE](../../LICENCE). YouRec's original name and icon remain
reserved by Salvatore Sanfilippo. Neither project's source license grants
permission to use its branding.
